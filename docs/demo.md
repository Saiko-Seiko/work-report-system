# デモの進めかた（12〜15分）

概要書を書かれた方が一番気にされているのは、たぶん次の5つです。
この順に見せると、話が早いはずです。

1. さくらの共用サーバで本当に動くのか
2. 通信が切れたら入力は消えないのか
3. マイク入力は本当に使えるのか
4. 署名は現場で書けるのか
5. PDFは紙と同じ見た目になるのか

---

## 準備

```
setup.cmd      デモデータを入れ直す（交換部品10,000件を含む）
serve.cmd      開発サーバを起動
```

ブラウザを2つ開いておくと切り替えが楽です。

| 用途 | URL | ID / パスワード |
|---|---|---|
| 現場（タブレット） | `http://localhost:8080/login` | `ABCDE0001` / `pass1234` |
| 事務局（PC） | `http://localhost:8080/admin/login` | `admin` / `admin1234` |

現場側は、ブラウザの開発ツールでタブレット表示（**768 × 1024**）にしておきます。
Chromeなら F12 →「Toggle device toolbar」→ サイズを 768 × 1024 に。

---

## 1. ログイン（1分）

`/login` を開く。

- 「**ユーザーID,パスワードを保持**」にチェックを入れてログイン
- ひとこと：**パスワードそのものは端末に残していません。**その端末だけで使える使い捨ての合鍵を置いて、使うたびに作り替えています。タブレットを紛失したときのためです

### 3回ロックを見せる場合

別のタブで `/login` を開き、`ABCDE0003` に間違ったパスワードを3回入れます。

```
1回目「あと2回間違えるとロックされます」
2回目「あと1回…」
3回目「3回間違えたため、ロックしました。解除は事務局にご連絡ください」
```

解除は管理者サイト →「ユーザー登録」→ 該当行の「ロック解除」。**あとで見せます**と言って先に進みます。

## 2. 報告書を作る（4分）

ダッシュボード →「**作成（新規で作成）**」

### 2-1 基本情報

- 作成日・作業日は**タップするとOSのカレンダー**が出ます（自前のカレンダーより誤操作が少ないので）
- 作業日を選ぶと**右に曜日**が出ます
- 病院名の欄をタップすると**過去に入力した病院名が候補**に出ます
  - ひとこと：これが無いと「横浜市立大学附属病院」と「横浜市大附属病院」が別物として溜まって、あとで集計できなくなります
- **マイクのボタン**を押して喋る 👉 **見せどころ③**
  - ボタンが赤く脈打ち、喋った内容がそのまま欄に入ります
  - ひとこと：AndroidタブレットのChromeなら追加費用ゼロで動きます。iPadのSafariは音声認識が不安定なので、その場合はボタンを出さずに「キーボードのマイクをお使いください」とご案内する画面が出ます
- 作業者は「選択」から複数選べます。名簿に無い人は直接入力
- わざと病院名を空にして「つぎへ」👉 赤字で必須エラー（**全て必須項目**のご指定どおり）

### 2-2 作業内容

- 機種名マスタの12件が並びます。台数を `[-] 0 [+]` で
- 使わない機種は「削除」で消せます（**対象外は削除する**）
- 消しすぎたら「機種を戻す」で戻せます

### 2-3 交換部品 👉 **見せどころ**

- 画面上部に「**全10,000点**」と出ています。**実際に1万件入れてあります**
- 「よく使う順」で概要書に並んでいた11点が先頭に出ます
- 検索欄に `ミズ` と入れて「検索」 👉 **ヨミガナで引けます**
- ボタンを押して「**50音順**」に切り替え 👉 圧力計（アツリョクケイ）から並びます
  - ひとこと：ヨミガナの列がないと、漢字とアルファベットが混ざったマスタは50音で並びません。**インポート用のExcelに1列足していただきたい**のはこのためです
- 数量を入れてから、もう一度検索 👉 **選んだ部品は上に残ります**
  - ひとこと：検索し直すたびに選んだものが消えると、入れたつもりで抜ける事故が起きます

### 2-4 測定値・報告事項

- 1件を1枚のカードにしています
  - ひとこと：幅768pxに5列を横並びにすると窮屈で押し間違えます。横スクロールより確実です
- 積算時間に `999999` を入れて「つぎへ」👉 `0〜100000` のエラー
- 製造年月はOSの年月ピッカー
- 報告事項の「選択」→ 定型文にチェック →「選んだ文章を追記」

### 2-5 確認署名

- **チェックが5つ揃うまで作業者の欄が押せません**（概要書 2-5-3 のとおり）
- チェックを全部入れると押せるようになります

## 3. サイン 👉 **見せどころ④**（1分）

「サイン入力」→ 独立した画面になります。

- ひとこと：概要書に「唯一、顧客が操作する画面なので1画面別にしたい」とあったので、ヘッダーもメニューも出していません
- **指またはマウスで書く**。線は太めにしてあります
- **手のひらが画面に触れても線になりません**（主に触れている指1本だけを拾っています）
- 「消去」で書き直し、「保存」で確認画面に戻り、点線内にサインが出ます

---

## 4. 通信が切れても消えない 👉 **見せどころ②**（3分）

**ここが一番大事です。** ヘッダーの下に緑の帯で「**サーバー送信済み**」と出ているのを見せてから：

1. 開発ツールの Network タブ →「**Offline**」に切り替え
2. 帯が**赤**に変わり「オフライン：入力はこのまま続けられます」
3. **そのまま入力を続けて「つぎへ」を押す** 👉 次の画面がちゃんと開きます
   - ひとこと：あらかじめ画面を端末に取り込んであるので、圏外でも最後まで進めます
4. 帯が**橙**になり「端末保存中（未送信 2件）」
5. Network を「**Online**」に戻す
6. 「通信が回復し、溜めていた入力をサーバーへ送信しました」と出て、帯が**緑**に戻る

**二重登録の話**：
「電波の切れ際で、サーバーには届いたのに応答が返らないことがあります。その時に端末が送り直しても、**受付番号を付けているので一度しか処理しません**。同じ報告書が2件できることはありません」

## 5. PDF 👉 **見せどころ⑤**（2分）

完了画面 →「報告書のプレビュー」

- 概要書のプレビュー画像と見比べていただく
- **Ctrl+P** で印刷ダイアログ 👉 1枚に収まっているのを確認
- ひとこと：**エクセルのテンプレートに流し込むやり方は、さくらの共用サーバーでは変換ソフトが置けないので使えません。**同じ体裁をHTML/CSSで組み直しました。画面と紙の見た目がずれませんし、**報告事項が長いときは自動で文字を詰めて1枚に収めます**
- 「印刷」→ ブラウザの印刷画面
- 「メール送信」→ 左に報告書、右に入力欄。宛先の形式チェックが効きます
  - 送信すると「**送信しました**」のダイアログ（プロトタイプでは記録のみ、と正直に出しています）

## 6. 社内用報告書と「完了（請求済）」（2分）

完了画面 →「**社内用報告書へ**」

- 客先に出した内容が写っています（**修正できます**）
- 移動および作業時間：往・作業・復を入れると**右に時間が自動計算**されます
  - ひとこと：請求のもとになる数字なので、打ち間違いにその場で気づけるようにしました
- 4-6 で「**完了**」→「本当によいですか？」→ OK
- 一覧に戻ると、その報告書の「**状態**」が「**完**」になっています

これで概要書5章の ①〜⑧ が一周しました。

## 7. 一覧（1分）

「報告書一覧」

- 概要書の表そのままです（署名・PDF・Mail回数・社内用・状態）
- 見出しを押すと **No.・作業日・作成日・病院名**で並べ替えできます
- PDFの「●」でプレビュー、病院名で修正画面へ
- 「**＋**」で**この報告書を写して新規作成**
  - ひとこと：同じ病院を毎回ゼロから打ち直さずに済みます。**サインと担当者、提出やメールの記録は引き継ぎません**（前回の作業の事実が新しい報告書に付いてくるとまずいので）。測定値も部屋名と型式まで写して、実測値は空にしています

## 8. 事務局側（2分）

管理者サイト（`/admin/login`）。**1600 × 900** で。

- **ダッシュボード**：全社の報告書が並びます。検索欄に病院名・協力会社名・報告書No.
- 「PDF ●」を押すと**別タブでA4**が開きます（そのまま印刷できます）
- **ユーザー登録**：「＋追加」でアカウント発行。作業者1〜5も一緒に。**ロック解除**もここ
- **交換部品マスタ** 👉 **見せどころ**
  1. 「ダウンロード」→ CSVが落ちる（エクセルでそのまま開けます）
  2. 数行だけ直して保存
  3. 「インポート」→ **追加◯件・変更◯件・削除◯件**が出る
  4. 「この内容で取り込む」

  ひとこと：**概要書では「書き込む前にDBをクリア」となっていましたが、そのままだとファイルを間違えた瞬間に1万件が消えます。**部品名を鍵にした差分反映にして、取り込む前に自動で控えを取り、失敗したら丸ごと元に戻すようにしました。削除も消さずに隠すだけなので、**過去の報告書に載っている部品名は残ります**

## 締めに伝えること

- **依存ライブラリはゼロです。** FTPで上げれば動きます。ビルド作業もありません
- **自動テストを371項目書いてあります。**`test.cmd` を叩けば全部流れます
- 本番前に `php tools/preflight.php` を流すと、置き場所・権限・設定の消し忘れをまとめて確認できます

## 確認をお願いしたいこと（デモの最後に）

1. **現場のタブレットはiPadですか、Androidですか** — 音声認識の動き方が変わります
2. **交換部品のExcelにヨミガナの列を足していただけますか** — 50音順に必要です
3. **パスワードの「半角英数8文字」は、ちょうど8文字ですか、8文字以上ですか** — いまは8文字以上で作っています
4. **メール件名の既定値「作業者完了報告書」は誤記でしょうか** — いまは「作業完了報告書」にしています
5. **確認署名の「確認事項3〜5」の文言** — 仮の文言を入れてあります

## うまくいかないときの逃げ道

| 症状 | 対処 |
|---|---|
| データがおかしくなった | `setup.cmd` で初期状態に戻ります（10秒） |
| マイクのボタンが出ない | `localhost` 以外ではHTTPSが要ります。案内の帯が出ているはずです |
| オフラインで画面が開かない | 一度オンラインで 2-1 を開いてください。そこで残りの画面を取り込みます |
| A4が2枚になっている | プレビューのURLに `?guide=1` を付けると、1枚目の境目に赤い線が出ます |
